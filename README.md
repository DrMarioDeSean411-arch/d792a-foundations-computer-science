## How to Use This Exam

### Sections 1–8 (practice mode)
1. Pick a section from the buttons at the top.
2. Read the question, including any code or table.
3. Click an answer. It locks, and the correct answer, an explanation, and an instructor note appear.
4. Use the numbered tabs to jump around. Green is correct, red is wrong.
5. Watch the competency breakdown at the bottom. Anything under 80% needs review.

### Review in Lab
After you answer a practice question, a blue **Review in Lab** button appears under the explanation. It opens the lab panel for that question's topic and highlights the matching section. **Back to question** returns you to the same question with your answer still locked. Visiting a lab never changes your score.

| Lab | Panels | What you can do |
|-----|--------|-----------------|
| C1 · OS Lab | Scheduler, OS Concepts | Run first-come first-served, round-robin and priority scheduling on the same four processes; edit burst times, priorities and the quantum; review the four OS benefits, OS types, kernel designs, drivers, file system and memory, and OS tools |
| C2 · Code Lab | List Methods, Core Concepts | Run Python (append, remove, sort, sorted) and JavaScript (slice, splice, forEach) methods and compare the list before and after, the return value, and whether the original changed; review abstraction, data types, operators, control flow, and functions |
| C3 · Algorithm Lab | Search Stepper, Big O Growth, Sorting & Structures | Step through linear and binary search; chart O(1) to O(n²) growth with a slider; step through bubble sort; compare data structure trade-offs; review benchmarking, profiling, and worst case |
| C4 · Data Lab | Profiler, Subsetting, Arrays & NumPy | Edit a small dataset and see counts, missing values, unique values, mean, median, mode, standard deviation, outliers, and repeated rows; build row and column subsets with the matching pandas and SQL; slice a 2D array and aggregate along an axis |

Links and the Labs button are **locked during the live timed simulation** so the simulation stays a fair readiness check. They unlock after you submit, and then appear on every question in the review.

### Section 9 (timed simulation)
This section behaves like the real thing.

1. Click **Begin timed attempt**. A 65-minute clock starts.
2. Answer 50 mixed questions. There is no feedback while you work. You can change answers and flag questions to revisit.
3. Click **Submit exam** when you are done, or let the clock run out and the attempt submits itself.
4. You get a score, a breakdown by competency, and a full explanation for every question.
5. Click **Retake simulation** to try again.

Work without notes or labs for the simulation. Treat the score as a readiness check before you schedule the official attempt.

## Topics Covered

**Competency 1 — Operating Systems**
The four practical OS benefits (security, portability, resource sharing, protection) · OS types (desktop, server, mobile, embedded) · the kernel and kernel designs (monolithic, microkernel, hybrid) · device drivers · programs versus processes · scheduling (first-come first-served, round-robin, priority) · file system organization · memory isolation · the GUI versus the OS beneath it · tools (chmod, top and htop, Task Manager, Disk Utility, the shell)

**Competency 2 — Program Foundations**
Abstraction and decomposition · sequence, selection, and iteration · variables and data types · type errors · arithmetic, comparison, and logical operators · parameters and return values · functions versus methods · packages and libraries · lists and dictionaries · Python list methods (append, remove, sort) · JavaScript array methods (slice, splice, forEach) · data representation

**Competency 3 — Algorithm Efficiency**
Big O (O(1), O(log n), O(n), O(n log n), O(n squared)) · array, linked list, hash table, stack, queue, and balanced tree trade-offs · linear and binary search · bubble, merge, and quick sort · worst case · benchmarking versus Big O · profiling · memory as part of efficiency · when a simple algorithm is the right choice

**Competency 4 — Data Profiling**
Profiling a dataset · subsetting (rows, columns, combined filters, SQL equivalents) · pandas commands (describe, isnull, groupby) · mean, median, mode, and standard deviation · outliers · missing values · uniqueness checks · data distribution and skew · 1D and 2D arrays · aggregation, filtering, indexing, and slicing · NumPy vectorization · pandas DataFrames
